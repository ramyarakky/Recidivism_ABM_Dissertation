# An Agent-Based Framework for Recidivism

**Predictive Modeling, Algorithmic Fairness Evaluation, and Synthetic Data Generation**

This repository contains the Python code and experiments developed for a PhD dissertation on recidivism using agent-based modeling (ABM). The research examines whether a simulated criminal justice system can reproduce empirical rearrest patterns, generate synthetic data for machine learning, and support controlled experiments on supervision-related disparities and reentry interventions.

The central outcome is **first recorded rearrest following release**. Events are generated by the model's behavioral, transition, supervision, and detection rules; synthetic records are not observations of actual individuals.

## Research objectives

1. **Calibration and validation:** Compare simulated cumulative first rearrest with Bureau of Justice Statistics (BJS) estimates while preserving differences by risk tier and offense category.
2. **Supervision-related disparities:** Compare a demographic-neutral baseline with simulations that explicitly vary supervision, detection, and other justice-system mechanisms.
3. **Predictive modeling and fairness:** Train classifiers using independent simulated cohorts and evaluate generalization, calibration, and subgroup fairness, with a separate National Institute of Justice (NIJ) empirical benchmark.
4. **Counterfactuals:** Examine hypothetical changes in employment, programs, housing stability, and reentry mechanisms.

## Model design

The model uses the [Mesa](https://mesa.readthedocs.io/) Python ABM framework. Each agent has demographic, criminal history, risk, employment, education, residence, program participation, and supervision attributes. The simulated justice states are:

```text
Trial → Prison → Supervision → Free / Community
```

The model advances in **monthly steps** and supports a **144-month warm-up** followed by a **108-month (nine-year) study period**. Experiment-specific population and intake settings differ by script. In the study follow-up, first rearrest is treated as an absorbing outcome. The model separates simulated processes from recorded/detected rearrest.

### Core implementation

- `agents/person.py`: agent behavior, state transitions, supervision and detection, interventions, and bias routing.
- `model/recidivism_model.py`: Mesa model, agents, data collection, calibration, and counterfactual settings.
- `generate_synthetic_agent.py`: agent initialization.
- `scoring.py`: risk scoring from live and initialized agent attributes.
- `config/risk_config.py`: risk weights, calibration targets, peer effects, and bias settings.
- `config/pcra_to_bjs.py`: PCRA tier benchmark support.
- `server.py` and `run.py`: interactive Mesa visualization.

## Empirical calibration

The code compares cumulative rearrest to the BJS nine-year follow-up benchmarks:

| Horizon | Target |
| --- | ---: |
| 3 years | 68.4% |
| 6 years | 79.4% |
| 9 years | 83.4% |

Year-one rearrest (43.9% in the model configuration) is monitored as a diagnostic, rather than used as a primary fitting target in the staged calibration script.

The calibration architecture distinguishes three target families:

1. **Aggregate BJS trajectory**: supervision-monitoring intensity and temporal-decay parameters.
2. **PCRA tier heterogeneity**: risk-contrast strength, evaluated at Low, Low-Moderate, Moderate, and High tiers.
3. **Offense heterogeneity**: offense-specific hazard shifts for Violent, Property, Drug, and Other/Public Order categories.

The code documents both methodological stages and the operational order of one-at-a-time (OAT) sweeps. Refer to `config/risk_config.py` and `experiments/OAT_Calibrate_BJS_PCRA.py` for current parameters and experiment settings.

## Supervision and demographic disparity experiments

A demographic-neutral baseline is calibrated before demographic-specific bias parameters are introduced. The `experiments/` scripts include two bias scopes:

- `supervision_only`: differential technical-violation detection and supervision-era rearrest mechanisms.
- `all_channels`: additional trial, sentencing, and supervision-assignment pathways.

Relevant scripts include `phase2_bias_supervision_only.py`, `phase2_bias_all_channels.py`, and their calibration variants. These experiments explore mechanisms that *could* produce disparities under the ABM assumptions; fitted coefficients are **not** direct causal estimates of real-world discrimination.

## Machine learning on independent ABM cohorts

`ml_analysis/generate_ml_synthetic_50k_multiseed.py` generates a pooled cohort of approximately **50,000 study-eligible synthetic records** from independent simulation seeds. It retains `simulation_id` and `simulation_seed` for group-aware train/test splitting.

`ml_analysis/ml_analysis_95_CI.py` evaluates cumulative outcomes `rearrest_3_yrs`, `rearrest_6_yrs`, and `rearrest_9_yrs`. Models include logistic regression, decision trees, random forests, extra trees, gradient boosting, AdaBoost, k-nearest neighbors, naive Bayes, support vector machines, and XGBoost.

The evaluation uses leave-one-simulation-seed-out outer testing with group-aware cross-validation on training seeds. Baseline-time predictors are used to reduce temporal leakage. Analyses cover discrimination, classification, calibration, demographic parity, disparate impact, true- and false-positive-rate differences, subgroup AUC/Brier scores, and across-seed stability.

### NIJ comparison

`ml_analysis_NIJ/ml_classification_NIJ.py` implements a **separate** benchmark on the NIJ Recidivism Challenge dataset, using a stratified 80/20 train/holdout split and five-fold cross-validation on training data. The NIJ analysis uses **1-, 2-, and 3-year** rearrest outcomes, while the synthetic ABM analysis uses **3-, 6-, and 9-year** outcomes. These horizon differences matter when interpreting comparisons.

## Counterfactual reentry experiments

Scripts in `counterfactual_analysis/` vary employment, program participation, residence stability, and other reentry mechanisms, with matched seeds used to support paired comparisons.

`counterfactual_analysis/counterfactual_analysis.py` supports employment and program sweeps and produces raw results, summary tables, paired effects, mechanism checks, and charts. Other files in the folder extend those experiments to additional reentry mechanisms. Findings describe **model-conditional scenarios**, not measured policy effects.

## Installation

The source uses package imports under `recidivism_abm`. For those imports to resolve, clone the repository **as `recidivism_abm`** and run module commands from its parent directory:

```bash
git clone https://github.com/ramyarakky/Recidivism_ABM_Dissertation.git recidivism_abm
cd recidivism_abm
python -m venv .venv
```

Activate the environment:

```bash
# Linux / macOS
source .venv/bin/activate

# Windows PowerShell
.venv\Scripts\Activate.ps1
```

The current code imports legacy Mesa APIs including `mesa.time.RandomActivation` and `mesa.visualization.ModularVisualization`. **Mesa 1.1.0** is a practical compatibility starting point; upgrading to newer Mesa versions may require code changes. A tested dependency lockfile is not currently included.

Install a starting set of analytical dependencies:

```bash
python -m pip install "mesa==1.1.0" numpy pandas scipy matplotlib scikit-learn joblib tqdm plotly xgboost psutil
```

Additional visualization or optional dependencies may be needed. This is a starting environment, not a verified requirements lock.

## Running experiments

Run the following commands **from the parent directory of `recidivism_abm/`**, after activating the virtual environment:

```bash
# Interactive Mesa visualization
python -m recidivism_abm/run.py

# Baseline Uncalibrated Run generating necessary visualizations using average across 20 simulation runs
python -m recidivism_abm/experiments/profile_run_multiseed_multirun_uncalibrated.py

# Calibrated Run generating necessary visualizations using average across 20 simulation runs
python -m recidivism_abm/experiments/profile_run_multiseed_multirun_calibrated.py 

# Inspect available command-line options
python -m recidivism_abm/ml_analysis/generate_ml_synthetic_50k_multiseed.py --help
python -m recidivism_abm/ml_analysis/ml_analysis_95_CI.py --help
python -m recidivism_abm/counterfactual_analysis/counterfactual_analysis.py --help

# BJS/PCRA/offense calibration (computationally demanding)
python -m recidivism_abm/experiments/OAT_Calibrate_BJS_PCRA.py
# Calibrated Run generating necessary visualizations using average across 20 simulation runs
python -m recidivism_abm/experiments/profile_run_multiseed_multirun_calibrated.py 

```

Some older or exploratory scripts assume particular paths, datasets, output directories, or HPC worker counts. Review configuration constants and script headers before running large experiments. Start with reduced agent and replication settings to verify the environment.

## Reproducibility considerations

- Preserve independent simulation seeds and IDs in any pooled dataset.
- Separate warm-up dynamics from the post-release study cohort.
- Distinguish empirical BJS/NIJ records from synthetic agent-level outcomes.
- Report both aggregate calibration errors and heterogeneity by group, tier, and offense.
- Treat performance on independently seeded simulations as distinct from row-wise random splitting.
- Avoid using outcome or post-outcome variables as baseline predictors.
- Document worker counts, random seeds, inputs, parameters, and generated output locations for each experiment.
